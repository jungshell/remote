# 부서 문항 수집 템플릿

부서·사업에서 쓰던 실제 설문 문항을 이 표에 적어 주세요.  
표가 어려우면 **원본 설문지 파일만** 주셔도 됩니다.

### 응답 방식 설명
- **5점**: 매우불만족~매우만족
- **NPS**: 0~10점 추천 의향
- **서술**: 자유롭게 쓰는 주관식
- **선택**: 보기 중 고르기 (보기도 적어 주세요)

## 공통 KPI와 겹치는 문항

이미 플랫폼에 있는 공통 문항과 비슷한 것이 있으면 표시해 주세요.

- 전반 만족
- 안내·절차
- 담당 응대
- 기대 부합
- 성장 도움
- 재참여 의향
- 추천(NPS)
- 개선 의견(서술)

→ 「같음 / 비슷함 / 부서 전용」 중 하나로 메모해 주시면 매핑이 빨라집니다.
