# 만족도 KPI 통합관리 플랫폼 설정 가이드

이 프로젝트는 1차 MVP를 무료 기반으로 운영하도록 설계했습니다.

- 데이터 저장: Google Sheets
- 파일 정리: Google Drive
- 자동화: Google Apps Script
- PDF 생성: Google Docs 템플릿 + Apps Script 변환
- 웹 배포: Vercel Free 또는 Cloudflare Pages
- AI 요약: Gemini API 무료 할당량 내 선택 적용

## 1. 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 2. Google Apps Script 배포

1. [Google Apps Script](https://script.google.com/)에 접속합니다.
2. 새 프로젝트를 만듭니다.
3. `apps-script/Code.gs` 내용을 복사해 붙여넣습니다.
4. `배포 > 새 배포`를 선택합니다.
5. 유형은 `웹 앱`으로 선택합니다.
6. 실행 권한은 `나`, 액세스 권한은 내부 테스트 단계에서는 `나만` 또는 `조직 사용자`로 설정합니다.
7. 배포 후 생성된 웹 앱 URL을 복사합니다.
8. 프로젝트 루트에 `.env.local` 파일을 만들고 아래처럼 입력합니다.

```env
NEXT_PUBLIC_GOOGLE_APPS_SCRIPT_URL=복사한_웹앱_URL
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

## 3. Google Drive 자동 폴더 구조

Apps Script는 아래 구조를 자동 생성합니다.

```text
만족도조사_통합플랫폼
└─ 2026
   └─ 본부
      └─ 사업
         └─ 세부사업
            └─ 1회차
               └─ 응답데이터 Sheet
```

회차별 Sheet 이름은 다음 규칙입니다.

```text
2026_세부사업명_1회차_응답데이터
```

응답 Sheet에는 아래 탭이 생성됩니다.

- `응답원본`: 문항별 점수가 한글 컬럼으로 펼쳐져 저장됩니다.
- `문항정보`: 문항 ID, 문항명, 척도, KPI 포함 여부를 관리합니다.
- `집계결과`: 응답수, 목표응답수, 응답률, 만족도, NPS를 자동 집계합니다.
- `주관식의견`: 개선의견만 별도로 모아 관리합니다.
- `개선과제`: 낮은 점수와 주관식 의견을 바탕으로 개선과제 초안을 자동 등록합니다.

`응답원본`의 주요 컬럼 예시는 아래와 같습니다.

```text
설문ID, 휴대폰뒤4자리, 제출일시, 전반만족, 절차편의, 담당응대, 기대부합,
성장도움, 재참여, 추천점수, 개선의견, 운영시간, 시간배분, 강의자료 ...
```

마지막 `응답JSON` 컬럼은 원본 백업용입니다.

Apps Script 코드를 수정한 뒤에는 반드시 `배포 관리 > 새 버전`으로 다시 배포해야 변경사항이 웹앱에 반영됩니다.

## 4. 응답 수정 방식

응답자는 설문 시작 시 휴대폰 번호 뒤 4자리를 입력합니다.

- 같은 설문ID + 같은 뒤 4자리 응답이 있으면 기존 응답을 수정합니다.
- 전체 전화번호는 수집하지 않습니다.
- 뒤 4자리는 중복응답 방지와 수정 확인용으로만 사용합니다.

## 5. PDF 보고서

PDF는 2종으로 분리합니다.

- 공식 보고용 PDF: 결재·외부 제출용 요약 보고서
- 내부 분석용 PDF: 문항별 분포, 주관식, 개선과제, 연도별 비교 포함

PDF는 Apps Script가 Google Docs 문서를 자동 작성한 뒤 PDF로 변환하여 회차 폴더에 저장합니다.

- 공식 보고용 PDF: 사업 개요, 핵심 지표, 주요 해석, 개선 의견/과제 요약
- 내부 분석용 PDF: 공식 보고 항목 + 문항정보, 주관식 의견, 개선과제, 응답 원본 요약

템플릿 문서를 따로 만들지 않아도 1차 보고서 생성이 가능합니다. 향후 기관 공식 서식이 확정되면 Google Docs 템플릿 방식으로 확장할 수 있습니다.

## 6. Gemini API 선택 적용

무료 우선 운영에서는 AI 기능을 필수로 두지 않습니다. 필요 시 Gemini API를 아래 용도로만 선택 적용합니다.

- 주관식 의견 요약
- 반복 불만 키워드 추출
- 개선과제 초안 생성
- 보고서 요약 문안 생성

`.env.local`에 아래 값을 추가합니다.

```env
GEMINI_API_KEY=발급받은_Gemini_API_Key
```

AI 결과는 공식 보고서에 바로 반영하지 말고, 담당자 확인 후 반영하는 방식이 안전합니다.

## 7. 나중에 유료 전환을 검토할 항목

초기에는 모두 제외합니다.

- 문자/알림톡 리마인드
- 기관 SSO
- 대용량 DB
- 서버 기반 고품질 PDF 렌더링
- 대량 AI 요약

응답량, 보안 요구, 보고서 품질 요구가 커질 때 선택적으로 전환합니다.
